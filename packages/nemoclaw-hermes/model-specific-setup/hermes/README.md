# Hermes Model-Specific Setup

Hermes model/provider compatibility manifests belong in this directory and must declare `"agent": "hermes"`.

This directory has no compatibility manifests at this time.
Add one only after a Hermes-specific failure or acceptance test proves that Hermes needs compatibility behavior.
Hermes executable wrappers and runtime code belong under `packages/nemoclaw-hermes/`.
Registry manifests must stay declarative.
