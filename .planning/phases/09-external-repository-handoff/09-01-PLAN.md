- D-01: Phase 8 qualification is the mandatory entry and rollback gate.
- D-02: Maintainer acceptance must name repositories, owners, transport, trust, retention, revocation, incidents, and validation.
- D-03: Repository handoff preserves the in-tree descriptor, controller, tests, and image behavior.
- D-04: NemoClaw verifies exact package and platform-image identities with provenance and central conformance.
- D-05: Discovery remains explicit and never imports a Python entry point or package host callback.
- D-06: Handoff order is Deep Agents Code, managed Hermes, then OpenClaw, with qualification after each.
- D-07: The static standard release set changes in one reviewed pull request only after all three external packages pass central qualification.
- D-08: Canonical Phase 8 package bytes and digest define handoff equivalence; any packaged difference is a new release.
- D-09: One accepted transport has a core-owned resolve, bounded fetch, verify, and cache path that hands verified bytes to existing registration transactions.
- D-10: Immutable qualification references and static support status remain separate, with reviewed change and incident owners.
- D-11: The handoff preserves exactly the three existing package-local descendant wrappers until a later accepted exact-OpenShell parity decision.
</decision_coverage>
