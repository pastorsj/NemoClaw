# Phase 3 Plan 2: OpenClaw Fabric Adapter

<objective>
Connect OpenClaw to the generic Fabric runner through package-owned code and data. Preserve native
commands, configuration behavior, and NemoClaw lifecycle ownership.
</objective>

<tasks>

<task type="auto">
  <name>Task 1: Add the OpenClaw adapter</name>
  <action>Add the package-owned adapter, descriptor, exact dependency lock, generated credential-free Fabric configuration, manifest command, and image installation. Invoke the native OpenClaw agent command through a mode-0600 prompt file. Normalize only assistant output and terminate the process group on cancellation or timeout.</action>
  <verify>`npm --prefix packages/nemoclaw-openclaw run test:fabric` and `npm --prefix packages/nemoclaw-openclaw run test:fabric:composed` pass.</verify>
</task>

<task type="auto">
  <name>Task 2: Preserve OpenClaw configuration integrity</name>
  <action>Generate, hash, restore, reconcile, unlock, and seal `openclaw.json` and `fabric.json` together. Keep `fabric.json` mode 0600 while mutable and mode 0444 while Shields is active. Provision the Fabric artifact directory before the locked-root transition.</action>
  <verify>OpenClaw config, runtime, recovery, privilege, startup, and image tests pass.</verify>
</task>

<task type="auto">
  <name>Task 3: Extend lifecycle evidence</name>
  <action>Use the public Fabric command in the existing inference-switch, Shields, managed-activation, and rebuild E2E paths. Add deterministic support tests for result parsing, redaction, timeout, and artifact assertions. Do not add a target registry or messaging test.</action>
  <verify>Focused core tests, package tests, E2E-support tests, semantic phase checks, CLI typecheck, and diff checks pass.</verify>
</task>

</tasks>
