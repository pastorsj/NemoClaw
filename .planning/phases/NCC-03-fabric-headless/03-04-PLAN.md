# Phase 3 Plan 4: Non-Messaging Qualification

<objective>
Run one common, bounded qualification sequence for the OpenClaw and Hermes Fabric paths. Use live
environments only for Docker, OpenShell, policy, process, and inference boundaries.
</objective>

<tasks>

<task type="auto">
  <name>Task 1: Close deterministic gates</name>
  <action>Run the aggregate Fabric lane, both package suites, focused core lifecycle tests, the complete E2E-support project, project membership, semantic phase checks, CLI typecheck, repository checks, and diff checks. Rerun affected lanes after final edits or hook fixes.</action>
  <verify>Record each command, result, and skip reason in `03-QUALIFICATION.md`.</verify>
</task>

<task type="auto">
  <name>Task 2: Exercise the Mac boundary</name>
  <action>On isolated local state, build and onboard one OpenClaw and one Hermes sandbox without messaging. Run a public Fabric turn, restart the gateway, switch inference, enable and disable Shields, rebuild, and repeat the turn where the existing target supports that boundary. Remove only task-owned resources.</action>
  <verify>The qualification record contains exact source and package identity, platform, outcomes, redaction checks, and bounded cleanup.</verify>
</task>

<task type="auto">
  <name>Task 3: Exercise the Brev boundary</name>
  <action>Transfer the exact candidate tree to the approved Brev instance without repository credentials. Use the approved inference environment. Run the existing non-messaging managed-activation, restart, inference-switch, Shields, and rebuild targets for OpenClaw and Hermes. Do not run messaging targets or broad retries.</action>
  <verify>The qualification record contains target results, sandbox and gateway cleanup, and any evidence-backed limitation. Brev remains pending until every recorded command finishes.</verify>
</task>

</tasks>

<success_criteria>

- The record calls this local-fork development evidence, not release qualification.

</success_criteria>
