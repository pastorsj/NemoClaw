<threat_model>

- **T-18-01 — Partial legacy migration (critical):** A crash leaves one owner's session and registry
  on different authorities. Mitigation: deterministic locks, per-owner CAS, same-owner peer
  adoption, and rerun tests.
- **T-18-02 — Upgrade before recovery (critical):** OpenShell changes before required bytes exist.
  Mitigation: typed reconciliation is a hard gate before backup and runtime work.
- **T-18-03 — Candidate promotion (high):** Pi or NemoCUA receives an ordinary package identity.
  Mitigation: standard-only shared migration and explicit candidate regression cases.
- **T-18-04 — Shell authority duplication (high):** Bash interprets durable schemas or package
  metadata. Mitigation: one hidden typed command with closed outcomes.
- **T-18-05 — Cross-owner contamination (critical):** One sandbox's identity or migration time is
  treated as authority for another. Mitigation: exact sandbox-name owner grouping and independent
  reconciliation tests.
- **T-18-06 — Recovery-record invention (critical):** An orphaned legacy retained record is assigned
  the newest bundled bytes. Mitigation: require one same-name exact registry owner and copy identity
  only after shared owner reconciliation.

</threat_model>
