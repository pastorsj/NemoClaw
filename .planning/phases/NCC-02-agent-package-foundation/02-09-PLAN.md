<threat_model>

- **T-09-01 — Pending-state field loss (critical):** Identity disappears between route and policy
  records. Mitigation: exact-key parser/serializer and round-trip tests at each stage.
- **T-09-02 — Schema downgrade (high):** Malformed present state is interpreted as legacy absence.
  Mitigation: explicit invalid-state preservation and mutation refusal fixtures.
- **T-09-03 — Provenance mismatch (high):** A migration audit record is attached to another
  identity. Mitigation: shared pair validation and full-field equality.
- **T-09-04 — Candidate fabrication (high):** A candidate agent name creates package authority.
  Mitigation: no inference/population in schema code and candidate absence tests.
- **T-09-05 — Secret injection (high):** Registry extras persist credentials or paths. Mitigation:
  closed secret-free schemas and security-lane negative fixtures.

</threat_model>
