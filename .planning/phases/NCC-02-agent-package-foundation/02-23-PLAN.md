<threat_model>

- **T-23-01 — False live evidence (critical):** A list or planner command is reported as execution.
  Mitigation: metadata-only labels and separate manual-run sections.
- **T-23-02 — Secret disclosure (critical):** Inference credentials or endpoints enter logs.
  Mitigation: existing redacted secret mechanism plus an explicit artifact scan.
- **T-23-03 — Shared-host destruction (critical):** Qualification removes unrelated state.
  Mitigation: isolated accounts, pre-action inventory, exact resource names, and no broad cleanup.
- **T-23-04 — Identity drift (critical):** Resume or rebuild uses a newer active package.
  Mitigation: full identity comparison across receipt, session, manifest, and registry.
- **T-23-05 — Evidence overclaim (high):** Manual development observations are called release proof.
  Mitigation: prominent scope labels and explicit release-owner boundary.
- **T-23-06 — Unsafe cancellation demo (critical):** The walkthrough resumes or deletes a retained
  sandbox by mutable name. Mitigation: a separate final cancellation resource, same-name refusal
  evidence, and explicit identity-bound operator handoff.

</threat_model>
