<threat_model>

- **T-04-01 — Unreviewed package inclusion (critical):** A directory becomes available by presence.
  Mitigation: closed reviewed declarations and built-output validation.
- **T-04-02 — Candidate promotion (high):** Pi or NemoCUA enters the standard list. Mitigation:
  exact accepted set plus candidate exclusion tests.
- **T-04-03 — Build/source escape (critical):** A declaration copies arbitrary host data.
  Mitigation: repository containment, no-follow source checks, and exact destination map.
- **T-04-03A — Transitional dependency concealment (high):** A copied shared blueprint tree is
  mistaken for package self-containment. Mitigation: declare and digest the exact current shared
  dependency, exclude arbitrary roots, and make its Phase 3 removal an explicit contract test.
- **T-04-04 — Publication leakage (high):** Tests, credentials, caches, or host callbacks ship.
  Mitigation: explicit copy allowlist and `npm pack --dry-run` contract tests.
- **T-04-05 — Damaged-state repair by fallback (high):** Catalogue masks corruption. Mitigation:
  explicit damaged state and fail-closed resolution.

</threat_model>
