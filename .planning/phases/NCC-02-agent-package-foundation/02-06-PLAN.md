<threat_model>

- **T-06-01 — Ambient package activation (critical):** A path, URL, or global module becomes
  installable. Mitigation: exact reviewed catalogue/alias resolution only.
- **T-06-02 — Install-time code execution (critical):** A package hook runs on the host. Mitigation:
  data-only install service and process sentinel assertions.
- **T-06-03 — Command metadata drift (medium):** Discovery, help display, docs, and dispatch disagree.
  Mitigation: compiled oclif/display assertions, spawned processes, and CLI/docs parity.
- **T-06-04 — Test state leakage (high):** A process contract changes the developer store.
  Mitigation: isolated HOME, exact postconditions, and cleanup in `finally`.

</threat_model>
