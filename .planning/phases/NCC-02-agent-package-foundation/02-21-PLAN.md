or active package pointer. The whole rebuild must use one authority while retaining today's
candidate-only Pi and NemoCUA behavior.

regressions for drift and candidate compatibility.

  Mitigation: exact registry, session, receipt, and object equality before harness-owned repair.
- **T-21-03 — Capability confusion (high):** Messaging or dashboard behavior is selected from a different definition.
  Mitigation: derive capabilities only from the pinned definition and validate its identity.

  Mitigation: explicit qualified candidate branch and null-identity regression coverage.
