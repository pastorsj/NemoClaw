<threat_model>

- **T-11-01 — Build-context substitution (critical):** Docker copies repository bytes after exact
  package selection. Mitigation: definition-rooted context at every current call site.
- **T-11-02 — Provenance collision (high):** Different package roots share one local base tag.
  Mitigation: trusted root participates in build provenance and tag derivation.
- **T-11-03 — Core-path capture (high):** Package root redirects credentials or core policy state.
  Mitigation: change only agent-owned asset roots and retain core-owned paths.
- **T-11-04 — Lifecycle duplication (high):** Package image code creates a second Docker flow.
  Mitigation: reuse current base-image and sandbox-create orchestration only.

</threat_model>
