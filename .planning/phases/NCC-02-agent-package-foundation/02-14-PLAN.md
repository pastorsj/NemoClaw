<threat_model>

- **T-14-01 — Resume substitution (critical):** Flag, environment, or pointer selects different
  bytes. Mitigation: session identity validation before resume-session entry.
- **T-14-02 — Diagnostic mutation (high):** Conflict recording changes session state before refusal.
  Mitigation: reject package conflicts before `recordResumeConflict` is reachable.
- **T-14-03 — Destructive agent transition (critical):** Mismatch clears state or stops the router.
  Mitigation: make `resumeAgentChanged` unreachable on package mismatch.
- **T-14-04 — Candidate identity fabrication (high):** A candidate session is coerced into a standard
  package. Mitigation: preserve existing candidate gates and null package authority.
- **T-14-05 — Pre-recovery owner overwrite (critical):** Legacy preparation mutates the durable
  evidence portable recovery consumes. Mitigation: read-only preparation before `.run()` and
  committing migration only inside its recovered operation.

</threat_model>
