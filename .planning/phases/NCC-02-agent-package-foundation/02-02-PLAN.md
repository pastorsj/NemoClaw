<threat_model>

- **T-02-01 — Archive/path escape (critical):** A package writes outside its object. Mitigation:
  closed relative paths, normalized duplicate checks, no-follow traversal, and containment tests.
- **T-02-02 — Filesystem race (high):** Source or ancestor changes after validation. Mitigation:
  captured device/inode/metadata, verified copy, post-copy recheck, and private staging.
- **T-02-03 — Host code execution (critical):** Parsing imports or invokes attacker content.
  Mitigation: data-only schema, explicit rejection of executable entry fields, and no import hooks.
- **T-02-04 — Resource exhaustion (high):** Deep or oversized trees consume disk or memory.
  Mitigation: tested metadata, path, file, entry, depth, and total-byte constants.
- **T-02-05 — Terminal injection (medium):** Display metadata contains controls. Mitigation:
  bounded control-filtered strings before rendering.

</threat_model>
