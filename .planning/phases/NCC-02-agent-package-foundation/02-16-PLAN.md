<threat_model>

- **T-16-01 — Recreate substitution (critical):** Recreate follows a newer active object.
  Mitigation: package identity in intent, fingerprint, transaction, and journal.
- **T-16-02 — Replay substitution (critical):** Checkpoint replay infers missing package state.
  Mitigation: exact v5 identity and pinned-object resolution.
- **T-16-03 — Partial durable propagation (high):** Types carry identity but serializer drops it.
  Mitigation: production-shape round-trip tests.
- **T-16-04 — Candidate coercion (high):** Candidate absence is treated as OpenClaw package state.
  Mitigation: explicit non-package-managed candidate branch.

</threat_model>
