<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Signed or checked-in release data to supported selection | Release metadata authorizes standard package presentation and exact execution identity. |
| User-installed index to catalogue | A local receipt must not impersonate a standard package or alias. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-05 | Spoofing | Standard package identity | mitigate | Reserve accepted IDs, aliases, labels, and exact tuples to the release set. |
| T-03-06 | Tampering | Release-set order and default | mitigate | Validate uniqueness, qualification, exact digests, and one explicit default. |
| T-03-07 | Downgrade | Missing or unsupported exact package | mitigate | Fail closed and report remediation; never select another version or runtime. |
| T-03-32 | Spoofing | Compatibility as support | mitigate | Keep installation, qualification evidence, static release-set support, and selection as distinct validated fields. |
</threat_model>
