<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Local archive path to staged filesystem | Attacker-controlled archive metadata can escape roots, create special files, or exhaust resources. |
| Staging to authoritative package index | Partial or divergent content must never become an installed authoritative record. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-08 | Tampering | Tar path and file type | mitigate | Canonicalize paths, reject links and special records, and materialize with no-follow semantics. |
| T-03-09 | Denial of Service | Compressed artifact | mitigate | Enforce compressed, expansion, file, depth, and metadata limits while streaming. |
| T-03-10 | Spoofing | Receipt authority | mitigate | Bind exact artifact claims while making qualification, support, and runtime observation unrepresentable in an installation receipt. |
| T-03-11 | Repudiation | Interrupted install | mitigate | Use one locked atomic index update and immutable content receipts. |
</threat_model>
