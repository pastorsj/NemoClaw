<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Host client to OpenShell | OpenShell owns the bounded helper process and each admitted image entrypoint or direct-exec process. The three named descendant compatibility wrappers remain ratcheted debt outside this protocol. |
| OpenShell to package controller | Package negotiation data is untrusted and grants no product observation, mutation, or lifecycle authority. |
| Controller bytes to host parser | Raw output can contain credentials, protocol injection, or misleading negotiation claims. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-15 | Spoofing | Controller response identity | mitigate | Repeat and compare the request nonce, package receipt, sandbox, image, and negotiated version. |
| T-03-16 | Tampering | Negotiation replay or downgrade | mitigate | Require a fresh nonce and a version from the core allowlist. |
| T-03-17 | Information Disclosure | Raw controller streams | mitigate | Bound in memory, redact only for immediate display, and forbid persistence. |
| T-03-18 | Elevation of Privilege | Negotiation response | mitigate | The schema has no native operation, product observation, effect, command, lifecycle, supervision, or host-path field. |
| T-03-19 | Denial of Service | Controller process | mitigate | Enforce deadlines and require OpenShell to cancel and reap the bounded helper operation. |
</threat_model>
