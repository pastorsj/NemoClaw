<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Developer checkout to packed artifact | Untracked or nested install state must not change shipped files or dependency identity. |
| Package workspace to host core | A workspace dependency must expose only its built public contract and must not import core implementation. |
| NemoClaw core to OpenShell | New OpenShell transport must pass through the reviewed client; exact accepted legacy call sites remain ratcheted until their named migration phase. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-28 | Spoofing | npm package identity | mitigate | Require unique accepted names and one root workspace lock. |
| T-03-29 | Tampering | Packed contents | mitigate | Compare explicit file allowlists and clean-copy canonical tree digests. |
| T-03-30 | Elevation of Privilege | Direct OpenShell or package call | mitigate | Reject new call sites and source imports outside the accepted boundaries. |
| T-03-31 | Repudiation | Architecture debt | mitigate | Bind every existing exception to a Phase 1 path, symbol, disposition, and count. |
</threat_model>
