<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| CLI argument to package ingestion | A user-controlled path selects untrusted bytes for parsing in the host process. |
| Package data to terminal or JSON output | Untrusted text can inject terminal controls or leak sensitive material. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-12 | Tampering | Local artifact path | mitigate | Resolve and verify one regular file, bind reads to one identity, and reject changing input. |
| T-03-13 | Spoofing | Standard package claim | mitigate | Compare the complete exact tuple against read-only release data. |
| T-03-14 | Information Disclosure | CLI diagnostics | mitigate | Render only validated receipt fields and core-owned messages; discard raw package output. |
</threat_model>
