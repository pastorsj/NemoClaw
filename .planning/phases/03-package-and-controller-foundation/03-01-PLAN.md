<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Untrusted package data to host parser | Descriptor and protocol bytes are attacker-controlled input in a credential-bearing process. |
| Schema to generated language bindings | A binding must not widen the wire contract. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-01 | Tampering | Descriptor parser | mitigate | Reject duplicate keys, unknown fields, malformed identities, and invalid cross-field combinations. |
| T-03-02 | Elevation of Privilege | Descriptor capabilities | mitigate | Use closed service, probe, state, credential, resource, and interaction fields with bounded parameters, no host operation, and trusted probe execution. |
| T-03-03 | Information Disclosure | Controller response | mitigate | Provide no credential or free-text response field and reject credential-shaped values. |
| T-03-04 | Denial of Service | Schema input | mitigate | Bound bytes, nodes, depth, strings, arrays, and numeric ranges before expensive work. |
</threat_model>
