# Phase 4 Plan 3: OpenClaw Extraction

<objective>
Make `packages/nemoclaw-openclaw` the sole owner of OpenClaw-native behavior and remove the largest
remaining implicit-runtime surface from core.
</objective>

<tasks>

<task type="auto">
  <name>Task 1: Complete OpenClaw package ownership</name>
  <action>Move remaining OpenClaw policy, model setup, configuration, restore, gateway, dashboard, pairing, MCP, messaging, session, subagent, skill, voice, diagnostics, compatibility, and runtime assets into the existing package folders. Preserve the native plugin location. Remove each duplicate root source after its package replacement is active.</action>
  <verify>The package archive and image contain every declared asset, and no package build or runtime path reads a sibling harness or root OpenClaw source.</verify>
</task>

<task type="auto">
  <name>Task 2: Connect OpenClaw operations</name>
  <action>Wire the existing `config-runtime`, `config-restore`, `cli-grammar`, and MCP helpers through the finite loader. Add only required pairing, messaging, and image qualification operations. Keep process control and config guard at fixed in-sandbox paths. Delete native switches and fallback translations from core as each operation lands.</action>
  <verify>Native and Fabric turns, config generation and restore, inference switching, Shields, MCP, pairing, gateway recovery, messaging projection, backup, rebuild, and failure tests use the package implementation.</verify>
</task>

<task type="auto">
  <name>Task 3: Move detailed OpenClaw tests</name>
  <action>Move every OpenClaw-native root test, E2E assertion, fixture, helper, policy fixture, and source-shape test to the package. Keep plugin tests beside plugin source. Let the existing central E2E planner consume package-owned target data and assertions instead of an agent switch.</action>
  <verify>Package-only, composed, Fabric, plugin, archive, image, E2E-support, exactly-once suite membership, and core changed-test lanes pass.</verify>
</task>

<task type="auto">
  <name>Task 4: Remove implicit default behavior</name>
  <action>Delete ordinary null-to-OpenClaw branches after explicit identity is carried end to end. Keep only the named legacy-state migration required for existing installations, with tests that prove it cannot select behavior for new state.</action>
  <verify>The core source gate reports no OpenClaw behavior outside reviewed release data and the isolated compatibility migration.</verify>
</task>

</tasks>

<success_criteria>

- OpenClaw upstream changes are implemented and qualified in its package without a core release
  unless the semantic contract itself changes.
- Core has no OpenClaw default, grammar, path, protocol, or native config implementation.
- Current user commands and lifecycle outcomes remain unchanged.

</success_criteria>
