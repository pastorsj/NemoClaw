<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Package code to protected workflows | Package code runs in controlled jobs but cannot choose runners, suites, secrets, or release status. |
| Image registry, macOS host, and Brev to qualification evidence | Remote systems must prove exact artifacts, execution identity, outcomes, and cleanup. |
| Evidence bundle and reviewed release-set diff to release decision | One incomplete or mixed run must not qualify a release. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-08-05-01 | Spoofing | Package and image identity | mitigate | Bind every phase to exact release-set, package, OCI index, and platform digests. |
| T-08-05-02 | Tampering | Workflow selection | mitigate | Keep target, job, runner, credential, and qualification selection in the protected core planner and workflows. |
| T-08-05-03 | Information disclosure | Hosted inference and Brev | mitigate | Use protected secrets, redacted artifacts, no messaging credentials, and credential scanners. |
| T-08-05-04 | Repudiation | Release decision | mitigate | Record run, attempt, source, artifact IDs and digests, suite version, cleanup, reviewed diff, and maintainer acceptance. |
| T-08-05-05 | Denial of service | Remote cleanup | mitigate | Require terminal cleanup evidence and retain the previously shipped release on failure. |
| T-08-05-06 | Tampering | Release-set authority | mitigate | Change one checked-in static file only through ordinary reviewed PR and release gates. |
</threat_model>
