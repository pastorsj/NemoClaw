<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| npm tarball to host installation | Published static files enter the credential-bearing host CLI environment. |
| Installer transaction to package store | Partial or mismatched registration could select an unqualified package. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-08-03-01 | Tampering | Packed package and release set | mitigate | Assert exact file closure and validate digests before registration. |
| T-08-03-02 | Elevation of privilege | Installation | mitigate | Execute no package hook or callback and register only static validated data. |
| T-08-03-03 | Spoofing | Compatibility aliases | mitigate | Resolve aliases through exact release-set package IDs and fail when absent. |
| T-08-03-04 | Denial of service | Interrupted registration | mitigate | Use atomic idempotent receipts and transaction recovery tests. |
| T-08-03-05 | Elevation of privilege | Static support status | mitigate | Ordinary install and alias selection consume only reviewed `supported` entries and fail closed for `revoked` or `superseded`. |
</threat_model>
