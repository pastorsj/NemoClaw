## Trust Boundaries

| Boundary | Description |
|---|---|
| Package source to root test runner | Package-owned commands must not inject arbitrary central workflow behavior. |
| Copied package to checkout | Isolation tests must not succeed through ambient repository access. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-08-01-01 | Tampering | Root package command orchestration | mitigate | Use explicit reviewed commands and prohibit package-defined workflow or suite selection. |
| T-08-01-02 | Repudiation | Test ownership | mitigate | Enforce complete candidate-ledger mapping and disjoint project membership. |
| T-08-01-03 | Elevation of privilege | Ambient module resolution | mitigate | Run copied packages with cleared paths and negative checkout-import fixtures. |
| T-08-01-04 | Spoofing | Workspace package identity | mitigate | Require unique names and resolve every dependency edge and packed identity from the explicit workspace graph. |
| T-08-01-05 | Tampering | Published package contents | mitigate | Compare canonical manifests and byte-identical archives from two clean copies under one pinned toolchain. |
</threat_model>
