<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Package source to protected image build | Package code executes during build without receiving release credentials beyond scoped registry publication. |
| Workflow artifacts to release cohort | Evidence from six independent jobs becomes one reviewed release input. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-08-02-01 | Tampering | Platform and cohort artifacts | mitigate | Validate immutable IDs, digests, revisions, attempts, and complete exact tuples. |
| T-08-02-02 | Information disclosure | GitHub and registry credentials | mitigate | Keep secrets in trusted jobs and exclude them from package-controlled branches and evidence. |
| T-08-02-03 | Spoofing | Image repository and platform | mitigate | Enforce current exact repository names and native platform descriptors. |
| T-08-02-04 | Repudiation | Release evidence | mitigate | Bind workflow run, attempt, source, release set, package, image, controller, OpenShell, and suite identities. |
| T-08-02-05 | Elevation of privilege | Release-set authority | mitigate | Keep support status in reviewed core data and require trusted independent evidence before merge or release. |
</threat_model>
